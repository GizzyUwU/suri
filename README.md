## Getting Started

### Prerequisites

- BunJS
- Cargo

### Installation

1. Clone the repo

```sh
git clone https://github.com/gizzyuwu.git
```

2. Install SCCache
```sh
paru -S sccache
```

2. Install NPM packages

```sh
bun install
```

3. Run dev command
```sh
bun run dev
```
